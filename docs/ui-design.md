# 02. UI/UX 디자인 지침

## 1. 디자인 방향
첨부된 Dribbble의 Orvia 핀테크 랜딩 페이지를 시각적 레퍼런스로 삼는다. 금융 기능을 복제하는 것이 아니라 다음 디자인 특징을 Moodly에 적용한다.
- 차콜/블랙 외곽 배경과 밝은 회백색 메인 패널의 대비
- 넓은 여백과 간결한 타이포그래피
- 둥근 모서리, 얇은 경계선, 절제된 그림자
- 한 화면에서 핵심 메시지와 주요 행동이 명확하게 보이는 구성
- 중앙 또는 우측에 시각적 포인트가 있는 비대칭 레이아웃
- 과도한 장식, 복잡한 그라데이션, 불필요한 애니메이션 금지

## 2. 색상 토큰
아래 값은 구현의 시작점이다. 일관성 있게 CSS 변수로 관리한다.
- 페이지 배경: `#17191D`
- 메인 패널: `#F1F2F4`
- 카드/입력 배경: `#FFFFFF`
- 기본 텍스트: `#17191D`
- 보조 텍스트: `#777D86`
- 경계선: `#E1E4E8`
- 긍정 강조: `#168A55`
- 부정 강조: `#D94B4B`
- 중립 강조: `#64748B`
- 주요 버튼: `#111318`

색상만으로 결과를 구분하지 않는다. 반드시 긍정/부정/중립 텍스트와 아이콘 또는 보조 표시를 함께 제공한다.

## 3. 레이아웃
### 데스크톱
- 어두운 페이지 배경 위에 중앙 정렬된 밝은 메인 패널을 배치한다.
- 패널 최대 너비는 약 1,200px, 내부 여백은 넉넉하게 둔다.
- 상단: 작은 브랜드 로고/이름과 `소개`, `분석 방법` 정도의 간단한 내비게이션.
- 메인: 왼쪽에는 헤드라인·설명·입력창·분석 버튼, 오른쪽에는 감성 분석을 상징하는 추상 카드/말풍선 시각 요소 또는 결과 미리보기.
- 분석 결과는 입력 영역 아래 또는 오른쪽 결과 카드로 표시한다. 화면 폭에 따라 자연스럽게 재배치한다.
### 모바일
- 외곽 여백을 줄이고 한 열 레이아웃으로 전환한다.
- 내비게이션은 간소화한다.
- 입력창과 주요 버튼은 화면 너비에 맞춘다.
- 결과 카드는 입력창 바로 아래에 배치한다.
- 가로 스크롤이 생기지 않도록 한다.

## 4. 핵심 UI 구성
1. 브랜드 헤더: `moodly` 텍스트 로고.
2. 히어로 카피 예시: `문장 속 감정을 읽어보세요.` / `텍스트에 담긴 감성을 AI가 분석해 드립니다.`
3. 입력 카드: 라벨, 여러 줄 textarea, 글자 수 `0 / 5,000`.
4. 주요 CTA: `감성 분석하기`; 분석 중 `분석 중...`으로 변경.
5. 결과 카드:
   - 감성 레이블: 긍정 / 부정 / 중립
   - 신뢰도: 예) `82%`
   - 분석 이유: 1~3문장
   - 참고 안내: 신뢰도는 모델의 참고용 자기평가 점수
6. 오류 영역: 오류 문구와 재시도 안내.
7. 하단 고지: 결과는 참고용이며 문맥에 따라 달라질 수 있다는 안내.

## 5. 인터랙션 상태
- 초기: 입력창과 안내 문구만 표시, 결과 영역은 숨기거나 빈 상태로 표시.
- 입력: 글자 수 실시간 갱신.
- 유효하지 않은 입력: 입력창 근처에 검증 메시지.
- 로딩: 버튼 비활성화, 로딩 텍스트/스피너, 중복 제출 차단.
- 성공: 결과 카드 표시 및 부드러운 스크롤/포커스 이동(과도한 애니메이션 금지).
- 실패: 오류 메시지 표시, 입력 내용은 유지, 재시도 가능.

## 6. 접근성
- 모든 입력 요소에 연결된 `label`을 제공한다.
- 버튼은 실제 `<button>`을 사용한다.
- 결과 및 오류 업데이트 영역은 적절한 `aria-live`를 사용한다.
- 키보드 포커스 표시를 제거하지 않는다.
- 본문 텍스트 대비를 충분히 확보한다.
- `prefers-reduced-motion`을 존중한다.

## 7. 금지 사항
- 첨부 이미지의 은행 카드, 은행 메뉴, 저축 그래프 등 금융 도메인 요소를 그대로 사용하지 않는다.
- 실제 금융 서비스로 오해할 로고나 문구를 만들지 않는다.
- AI가 실제 감정을 확정적으로 판독한다고 표현하지 않는다.
- 모바일에서 데스크톱 화면을 축소한 형태로만 제공하지 않는다.
